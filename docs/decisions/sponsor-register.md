# Dated sponsor-register name signal

20 November 2026. Phase 2 requires the Home Office register as a separate signal. Network approval is pending, so support a user-downloaded CSV with explicit owner confirmation of its official source, publication date and column mapping. This is **owner-confirmed upload provenance**, not a claim that the app fetched/verified the official asset. No official full-file compatibility was verified in this cloud run. Defaults are convenience mappings; validate against the actual file.

Require an HTTPS assets.publishing.service.gov.uk/media/*.csv reference without credentials/query, a non-future date, distinct organisation/route/town headers and confirmation. Upload at most 50 MB; parse at most one million rows in the worker. UTF-8 BOM/quoted Unicode names are supported. Reject missing/duplicate headers, malformed/empty/oversized data and missing required organisation/route values before replacing the cache. Combine repeated names' routes/towns. Snapshot replacement is transactional and touches only public cache tables; owner jobs, statuses, Notes and histories are untouched. Raw uploads and metadata are retained for backup/provenance.

Match only Unicode-composed, case/whitespace-normalised names. Do not strip accents, punctuation or legal suffixes, expand brands or make fuzzy matches. Display exact-name-found / no exact-name-match with the dated source and file hash. A miss can reflect a brand/legal-name difference; a hit is a name signal, not verified legal-employer identity or sponsorship for this role. Dates remain explicit; do not invent licence expiry/currentness rules. Never turn a match into CONFIRMED_YES, eligibility or score weight. Legacy booleans without register provenance are not treated as checked evidence.

Serve the existing licensed_sponsor output from the current register lookup rather than rewriting job records. Keep the role-policy review separate. Existing server-only token/origin guards remain; only the register upload route gets a 50 MB limit and the specific public metadata header. All other request limits/headers stay unchanged. No dependencies added.

Tests use synthetic CSV data, not fabricated official records. Coverage includes conservative identity, source/confirmation/date validation, Unicode/CSV errors, row/body limits, previous-cache preservation, unchanged status/policy/score, legacy flags, real-worker browser upload/proxy/UI and backup/restore of cache/raw bytes. Actual official data compatibility and current legal-entity matching remain unverified.
